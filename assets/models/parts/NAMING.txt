PART MODEL NAMING CONVENTION
=============================

Format: part_<part_id>.glb

Drop your Meshy exports here, renamed to match the part IDs below.
These IDs map directly into the install-slot system.

  part_engine_block.glb
  part_cylinder_head.glb
  part_oil_pan.glb
  part_valve_cover.glb

NOTES
-----
- Export from Blender/Meshy as GLB (binary glTF), not GLTF+bin.
- Set real-world scale before export (Blender units = metres).
- Origin point = the part's natural mount point (bolt hole, bracket face, etc).
- Approximate real dimensions for reference:
    battery         0.24 x 0.17 x 0.19 m
    brake disc      0.28 x 0.02 x 0.28 m
    strut (full)    0.06 x 0.40 x 0.06 m
    gearbox         0.25 x 0.50 x 0.25 m
